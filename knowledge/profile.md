# プロフィール

## 基本情報

ラ・リキハンは、東京都を拠点にクラウドエンジニアを目指して学習と個人開発に取り組んでいます。クラウドインフラの構築と自動化に強い関心があります。

## キャリア目標

Web 開発、クラウド、AI を軸に、サービス開発の現場で価値を生み出せるエンジニアを目指しています。

将来的には、Web 開発とクラウド技術の両方に強く、AI 技術も実際のサービス開発に活用できるエンジニアになることを目標としています。そのために、必要な技術を自ら学び、実践を通じて身につけていく方針です。

## 自己 PR

本人が強みとしているのは、分からないことをそのままにせず、自分で調べ、試行錯誤しながら解決する姿勢です。

AWS の学習では、教材を読むだけでなく、実際に環境を構築して各サービスの役割や構成を確認しました。初めて扱う技術でも、必要な情報を探し、実際に試しながら理解することを大切にしています。

新しい技術や開発環境に取り組む際は、まず自分で考えて調べた上で、必要な点を質問する姿勢を意識しています。
